# Summary Method for spconform Objects

Computes and displays summary statistics of the prediction interval
widths generated by an `spconform` object.

## Usage

``` r
# S3 method for class 'spconform'
summary(object, ...)
```

## Arguments

- object:

  An object of class `"spconform"`.

- ...:

  Further arguments passed to or from other methods.

## Value

Invisibly returns the input object `object`.
