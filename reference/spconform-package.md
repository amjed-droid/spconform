# spconform: Conformal Prediction for Spatially and Spatio-Temporally Dependent Data

Provides distribution-free, model-agnostic prediction intervals for
spatially and spatio-temporally dependent data using localized conformal
calibration, fast k-NN proximity calculations, and comprehensive spatial
diagnostics.
